# Glassa Vault Downloader

Glassa Vault Downloader is a local-first Android media app built for:
- WhatsApp status media access through safe and user-authorized Android mechanisms
- legal media downloads from supported sources
- local media management
- premium Liquid Glass UI
- privacy-first architecture

## Project goals
- Open source
- Local-first
- Privacy-focused
- No developer-owned backend
- No login required
- No cloud sync required
- No hidden analytics
- No ads

## Stack
- Kotlin
- Jetpack Compose
- Material 3
- Room
- DataStore
- MediaStore
- GitHub Actions

## Build
This project is built through GitHub Actions.
Check the workflow inside `.github/workflows`.

## Privacy
Data is kept local on the device. No developer-owned backend is required for the app's core usage.

## Important
This app does not bypass platform protections or access private content without clear user authorization and valid Android access mechanisms.
